口腔照片自动分类工具 - 使用说明
================================

📋 快速开始
-------------
1. 安装依赖：
   pip install qrcode[pil] pyzbar Pillow

2. 运行程序：
   python main.py


🎨 界面功能说明
-------------

【顶部标题栏】
- 蓝色主题标题栏，显示程序名称和图标

【状态栏】（底部）
- 左侧状态图标：
  ✓ 绿色 = 就绪/成功
  📤 蓝色 = 处理中
  ⚠ 橙色 = 警告
  ✗ 红色 = 错误
- 中间状态文本：显示当前操作状态
- 右侧版本号


📝 Tab 1: 生成二维码
-------------

【患者信息卡片】
- 患者姓名：输入框（带工具提示）
- 就诊日期：默认当天，格式 YYYYMMDD
- 当日序号：自动生成后递增（001-999）

【操作按钮】
- 🔄 生成二维码：生成并预览
- 🗑️ 清空：重置所有输入

【二维码预览卡片】
- 220x220 像素预览区
- 📄 编码内容显示区（等宽字体）
- 💾 保存为图片：保存为 PNG
- 🖨️ 打开/打印：调用 Windows 默认打印


📁 Tab 2: 整理照片
-------------

【文件夹设置卡片】
- 源文件夹：选择包含照片的文件夹
- 输出文件夹：默认与源文件夹相同
- ✓ 复选框：取消可选择不同输出路径

【操作模式卡片】
- 📋 复制文件：保留原始文件
- ✂️ 移动文件：剪切到目标位置

【预览功能】
- 🔍 开始预览：扫描并显示分组
- 🔄 刷新：重新扫描
- 📋 预览列表：显示所有分组及照片数量
- 🖼️ 缩略图预览：点击列表项查看首张照片

【进度和执行】
- 📊 进度条：实时显示处理进度
- ✅ 确认执行：执行文件操作
- ❌ 取消：停止当前操作
- 📝 查看日志：查看详细处理记录


✨ 增强功能
-------------

1. 工具提示（Tooltips）
   - 鼠标悬停在输入框或按钮上显示帮助文字

2. 缩略图预览
   - 点击预览列表中的分组，自动显示该组第一张照片的缩略图

3. 处理日志
   - 点击"查看日志"可查看详细的文件操作记录
   - 日志包含：创建的文件夹、复制/移动的文件列表

4. 高 DPI 支持
   - 自动适配 Windows 高 DPI 显示器

5. 现代化 UI
   - Vista 主题风格
   - 蓝色标题栏
   - 彩色状态指示器
   - 卡片式布局


⚙️ 系统要求
-------------
- 操作系统：Windows 10/11
- Python 版本：3.10+
- 屏幕分辨率：建议 1280x720 以上


🔧 常见问题
-------------

Q: 程序启动时提示"缺少依赖"
A: 在命令行执行：pip install pyzbar

Q: pyzbar 导入错误
A: 尝试安装备选方案：
   pip install zbar-py
   或
   pip install zxing-cpp numpy

Q: 二维码识别失败
A: 确保二维码清晰、无反光、无模糊，拍摄时保持相机稳定

Q: 界面显示模糊（高 DPI 屏幕）
A: 程序已自动适配，如仍有问题请右键 main.py → 属性 → 兼容性 → 更改高 DPI 设置 → 勾选"替代高 DPI 缩放行为"
